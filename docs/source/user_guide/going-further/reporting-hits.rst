
🎯 Reporting hits
=================

So you found something with garak and you want to tell people! Good.&#x20;

AVID, the `AI Vulnerability Database <https://avidml.org/>`_\ , is keen to collect reports from things like LLM vulnerabilities. You can file an AVID report manually `here <https://airtable.com/shrOCPagOzxNpgV96>`_\ , and there's also support for automatic report building, using the program in ``analyze/report_avid.py``.
